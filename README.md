# 🤖 Jarvis

Голосовой помощник, который живёт на твоём компьютере и слушается голоса.
Говоришь «Джарвис, поставь на паузу» — музыка останавливается. «Джарвис, какая
погода» — отвечает вслух. Никаких колонок, подписок и облаков: всё крутится
у тебя дома.

> 💬 Читать умеет и по-русски, и по-английски, отвечает на том языке, на котором
> спросили.

Если ты далёк от программирования — ничего страшного. Ниже инструкция, где
каждый шаг расписан по кнопкам. 🙂

## 🎬 Что он умеет

**🎵 Музыка и видео**
```
— Джарвис, включи трек Dua Lipa Levitating
— Джарвис, пауза  ·  следующий трек  ·  громче
— Джарвис, поставь лайк
— Джарвис, перемотай на 30 секунд
— Джарвис, открой канал Лололошка
```

**🌐 Браузер**
```
— Джарвис, зайди на ютуб
— Джарвис, загугли как варить борщ
— Джарвис, найди в яндексе билеты в Прагу
— Джарвис, закрой вкладку
```

**🖥 Компьютер**
```
— Джарвис, открой фотошоп
— Джарвис, закрой стим
— Джарвис, громкость 30
— Джарвис, заблокируй компьютер
```

**❓ Вопросы и мелочи**
```
— Джарвис, какая погода
— Джарвис, кто такой Никола Тесла
— Джарвис, запомни: кабель XLR лежит в верхнем ящике

```

Можно позвать просто по имени — **«Джарвис»** — он отзовётся («Слушаю, сэр»)
и несколько секунд будет ждать команду уже без имени (`audio.wake_word.follow_up_s`).

## 🚀 Установка на Windows: 9 шагов

Понадобится: компьютер с Windows, микрофон (подойдёт любой, хоть в наушниках)
и интернет для скачивания. Времени — минут 20, из них 15 качается.

### 1️⃣ Поставить Python

Это язык, на котором Jarvis написан. Без него он не запустится.

1. Открой https://www.python.org/downloads/ и нажми жёлтую кнопку загрузки
   (нужна версия **3.13 или новее**).
2. Запусти скачанный файл.
3. ⚠️ **Самое важное:** внизу окна установщика поставь галочку
   **«Add python.exe to PATH»**. Без неё дальше ничего не заработает.
4. Нажми **Install Now** и дождись конца.

### 2️⃣ Скачать сам Jarvis

Вверху этой страницы: зелёная кнопка **Code** → **Download ZIP**.
Распакуй архив, например в `D:\Jarvis`.

> 📁 В пути к папке лучше без русских букв и пробелов — некоторые программы
> этого до сих пор не любят.

Должно получиться так, что файл `README.md` (этот самый) лежит прямо
в `D:\Jarvis`.

### 3️⃣ Открыть командную строку в этой папке

1. Открой папку `D:\Jarvis` в проводнике.
2. Щёлкни по адресной строке сверху, сотри всё и напиши `powershell`, Enter.

Откроется чёрное (или синее) окно — это и есть командная строка, она уже
«стоит» в нужной папке. Дальше все команды копируй туда и жми Enter.

### 4️⃣ Установить

Скопируй **обе** строки сразу:

```powershell
python -m venv .venv
.venv\Scripts\pip install -e ".[stt,voices,audio,windows]"
```

Первая создаёт отдельный уголок, чтобы Jarvis не мешался с другими
программами. Вторая скачивает всё, что ему нужно: распознавание речи, голоса,
работу со звуком. ☕ Это надолго — около 2 ГБ.

Красные строчки с надписью `WARNING` — это нормально. Плохо, только если
в конце написано `ERROR`.

### 5️⃣ Проверить, что всё встало

```powershell
.venv\Scripts\python -m jarvis --check
```

Он соберёт систему, напечатает список того, что умеет, и выйдет. Микрофон,
интернет и голоса для этого не нужны — это просто самопроверка. Если список
напечатался, установка удалась. ✅

### 6️⃣ Найти свой микрофон

```powershell
.venv\Scripts\python -m jarvis --devices
```

Покажет список микрофонов и колонок с номерами. Обычно ничего трогать не надо
— система сама возьмёт тот, что выбран в Windows. Но если Jarvis потом не будет
слышать, номер отсюда пригодится (см. [Настройки](#-настройки)).

### 7️⃣ Выбрать голос

```powershell
.venv\Scripts\python -m jarvis --try-voice ru
```

Он скачает голоса и по очереди произнесёт ими фразу — слушай и выбирай.
Понравившийся впиши в файл `config\config.yaml` (открывается «Блокнотом»):

```yaml
tts:
  voices:
    ru: vosk:male_1        # русский голос
    en: kokoro:bm_george   # английский
```

Вот эти два и стоят по умолчанию — отобраны на слух. Так что шаг можно
и пропустить. 😌

### 8️⃣ Дать ему «мозги» (по желанию, но очень советую)

Без этого шага Jarvis понимает только те фразы, которые знает наизусть.
С ключом — понимает и то, что сказано своими словами, и умеет просто
разговаривать.

1. Зарегистрируйся на https://openrouter.ai и создай ключ на странице
   https://openrouter.ai/keys.
2. В папке проекта найди файл `.env.example`, сделай его копию и назови
   копию просто `.env`.
3. Открой `.env` «Блокнотом» и впиши ключ:
   ```
   JARVIS_OPENROUTER_KEY=sk-or-v1-твой-ключ
   ```

Платить придётся по факту, копейки: обычная команда стоит меньше цента, а
разобранные фразы Jarvis **запоминает** и второй раз за них уже не платит.
Сколько потрачено — можно спросить голосом: «Джарвис, сколько потрачено».

> 🔒 Файл `.env` никуда не уходит и в репозиторий не попадает — он в списке
> игнорируемых. Ключи храни только в нём.

### 9️⃣ Запуск! 🎉

```powershell
.venv\Scripts\python -m jarvis
```

Дождись строчки о том, что всё запущено, и скажи в микрофон: **«Джарвис»**.
Он ответит. Закрыть — `Ctrl + C` в том же окне.

### 🖱 Бонус: запуск в один клик

Чтобы не набирать команды каждый раз, создай в папке `D:\Jarvis` текстовый
файл `start.bat` с таким содержимым:

```bat
@echo off
cd /d D:\Jarvis
.venv\Scripts\python -m jarvis
pause
```

Теперь Jarvis запускается двойным щелчком по нему. 👌

## 🧩 Расширение для браузера

Ставится за минуту и очень многое добавляет: без него Jarvis видит только
заголовки окон, а с ним — работает **вкладками** и умеет нажимать кнопки
внутри страницы (пауза, лайк, следующий трек, «включи трек …»).

Коротко: `chrome://extensions` → включить **режим разработчика** →
**«Загрузить распакованное расширение»** → указать папку `extension` внутри
проекта. Подробно, с Firefox и Яндекс Браузером — в
[extension/README.md](extension/README.md).

> 🔄 После обновления Jarvis расширение нужно перезагрузить руками, кнопкой
> «Обновить» на той же странице. Если версия устарела, Jarvis сам напишет
> об этом в журнале.

## 🧠 Что внутри: скиллы

Всё, что Jarvis умеет, — это **скиллы**: отдельные файлы в папке `skills/`.
Ядро про них ничего не знает, они просто лежат рядом и подхватываются при
запуске. Положил файл — появилась новая команда. Удалил — исчезла.
Сейчас в комплекте семь:

| | Скилл | Что делает |
|---|---|---|
| 🌐 | **browser** | Сайты, поиск, вкладки. «Зайди на ютуб», «загугли …», «закрой вкладку». Работает с любым браузером — ссылка отдаётся системе. |
| 🖱 | **page** | Всё, что обычно делают мышкой на странице: пауза, следующий трек, лайк, перемотка, «включи трек …», «нажми подписаться». Нужен браузерный плагин. |
| 🪟 | **windows** | Программы и компьютер: «открой фотошоп», «закрой стим», «громкость 30», «заблокируй компьютер». Только Windows. |
| 🔍 | **search** | Ответы на вопросы: «кто такой …», «что такое …». Википедия и DuckDuckGo, ключи не нужны. |
| ☀️ | **weather** | «Какая погода», «погода в Праге на завтра». Open-Meteo, ключи не нужны. |
| 💬 | **telegram** | Прочитать, пересказать переписку, ответить — от **своего** аккаунта, а не от бота. Требует отдельной настройки. |
| 📝 | **memory** | «Запомни, что …», «что ты помнишь», «что ты знаешь обо мне». |

Скиллы — это дополнение, а не суть проекта. Суть в том, что **любой из них
можно выкинуть, а свой — дописать за десять минут**, не трогая ядро.

### ✍️ Написать свой

Создай файл `skills/timer/skill.py`:

```python
from jarvis.core.contracts import ToolResult
from jarvis.core.skills import Skill, SkillMeta
from jarvis.core.tools import tool


class TimerSkill(Skill):
    meta = SkillMeta(name="timer", description="Таймеры")

    @tool(phrases=["поставь таймер на {minutes} минут"])
    async def start_timer(self, minutes: int) -> ToolResult:
        """Запустить таймер.

        :param minutes: длительность в минутах.
        """
        return ToolResult.success(minutes, speech=f"Таймер на {minutes} минут.")
```

Перезапусти — команда работает. Регистрировать нигде не нужно, конфиг не
трогается. Подробности — в [skills/README.md](skills/README.md).

## ⚙️ Настройки

Всё живёт в одном файле — `config/config.yaml`. Открывается «Блокнотом»,
меняется по одной строке.

| Что | Строка | Смысл |
|---|---|---|
| 🎯 Точность распознавания | `stt.model` | `tiny` → `base` → `small` → `medium`. Больше — точнее и медленнее |
| 🎤 Микрофон | `audio.input_device` | номер или часть имени из `--devices` |
| 👂 Чувствительность | `audio.vad.threshold` | `0` — измерить фон комнаты самому; иначе 0.01–0.05 |
| ⏱ Пауза до конца фразы | `audio.silence_ms` | больше — успеваешь подумать, меньше — быстрее отклик |
| 📛 Имя | `audio.wake_word.phrases` | можно звать не «Джарвис»; `mode: none` — вообще без имени |
| 🗣 Голоса | `tts.voices` | по голосу на язык |
| 🐢 Скорость речи | `tts.length_scale` | `<1` быстрее, `>1` медленнее |
| 🎩 Обращение | `persona.address` | «сэр» меняется на что угодно, пустая строка убирает |
| 🔎 Поисковик по умолчанию | `browser.engine` | `yandex`, `google`, … |

## 🆘 Если что-то не так

Запусти с подробным журналом — там видно, что именно он услышал:

```powershell
.venv\Scripts\python -m jarvis --log-level DEBUG
```

Полный журнал за день лежит в папке `logs\` — по файлу на дату.

| Симптом | Что делать |
|---|---|
| 🙉 **Не реагирует на имя** | Посмотри в журнале строку «Распознано: …». Если вместо «Джарвис» там «жаркость» — допиши услышанное в `audio.wake_word.aliases` |
| 🔇 **Вообще ничего не слышит** | Проверь микрофон через `--devices` и порог `audio.vad.threshold` |
| 🤨 **Слышит, но не выполняет** | Обычно это неточное распознавание («включи» → «в куче»). Лечится ключом OpenRouter — тогда непонятое разбирает языковая модель |
| 🗣 **Слышит сам себя** | Надень наушники: колонки произносят ответ, микрофон его ловит |
| 🐌 **Долго думает** | Возьми модель полегче: `stt.model: base` |
| 🌐 **Не управляет страницами** | Не установлено или не перезагружено расширение браузера |
| 💥 **Ошибка про память при запуске** | Whisper не влез в оперативку. Закрой тяжёлые программы или поставь `stt.model: base` |

## 🔊 Тонкая настройка голоса

Голос пишется как `движок:голос`, свой на каждый язык. Движков пять:

| Движок | Где считает | Вес | Чем хорош |
|---|---|---|---|
| `vosk` | локально | 750 МБ | Русский с живой интонацией — **лучший из локальных** |
| `kokoro` | локально | 338 МБ | Британские мужские голоса, быстро |
| `silero` | локально | 39 МБ + torch | Русский, 48 кГц |
| `piper` | локально | ~60 МБ | Самый лёгкий и быстрый |
| `edge` | облако | — | Нейроголоса Microsoft: естественнее локальных, но ~секунда задержки и нужен интернет |
| `xtts` | локально | ~1.8 ГБ | Говорит любым голосом с образца. **Только с видеокартой** |

Послушать подборки: `--try-voice jarvis` (британские мужские), `--try-voice ru`,
`--try-voice vosk`, `--try-voice cloud` (облачные Microsoft).

Один тембр на обоих языках делается клонированием: снимаешь образец с уже
выбранного голоса (`--make-reference vosk:male_1`) или с записи живого голоса
(`--make-reference мой-голос.wav`), потом пишешь `en: xtts:male_1`. Затея
имеет смысл **только при наличии видеокарты NVIDIA** — на процессоре XTTS
подвешивает ответ наглухо. Проверить:

```powershell
.venv\Scripts\python -c "import torch; print(torch.cuda.is_available())"
```

`False` — не включай.

## 🏗 Как это устроено

Это **фундамент, а не готовый продукт.** Функциональности намеренно немного;
ценность в том, что новая возможность добавляется файлом в `skills/`, а любую
часть (распознавание, синтез, языковую модель, память, шину, роутер) можно
заменить, не переписывая остальное. Полный разбор решений и обоснования —
в [ARCHITECTURE.md](ARCHITECTURE.md). Коротко:

* **Два канала связи.** Факты идут в шину событий, команды — через реестр
  инструментов с ответом и `await`. Скиллы никогда не импортируют друг друга.
* **Роутер отдаёт намерение, а не скилл.** Цепочка: точные фразы → синонимы →
  выученное → языковая модель → свободный диалог. Типовые команды до сети
  не доходят вообще.
* **Удачный разбор запоминается.** Модель поняла фразу, команда сработала —
  значит связка проверена делом, и со второго раза та же формулировка идёт
  бесплатно. Не то, что нужно, — скажи «не сохраняй в память».
* **Голос никогда не попадает в командную строку.** Услышанное сверяется
  с известным списком, запускается только найденное. Jarvis часто работает
  от администратора, и это принципиально.
* **Секреты — только в `.env`**, в коде нет ни ключей, ни путей.

```
jarvis/core/       ядро: конфиг, шина, инструменты, роутер, скиллы, LLM, память, аудио
skills/            плагины — всё, что Jarvis умеет
extension/         расширение браузера
config/config.yaml все настройки
memory/            что он запомнил
models/, logs/     модели и журналы
tests/             тесты
```

Тесты:

```bash
.venv/bin/python -m pytest
```

Проверяют именно швы архитектуры: доставку и изоляцию событий, вывод схем и
вызов инструментов, порядок резолверов (в том числе что известная фраза **не**
доходит до платной модели), загрузку и выгрузку скиллов.

## 🛠 Полезные команды

```powershell
.venv\Scripts\python -m jarvis                                # полный запуск
.venv\Scripts\python -m jarvis --check                        # самопроверка, быстро

```
