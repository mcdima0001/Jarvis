# Расширение Jarvis для браузера

Мост между ассистентом и браузером. Без него Jarvis видит только заголовки
окон и на каждый сайт открывает новое окно. С ним — работает вкладками:
открывает в существующем окне, переключается на уже открытую вкладку, закрывает
её по команде и делает внутри страницы то, что обычно делают мышкой: пауза,
следующий трек, лайк, перемотка, нажатие названной кнопки.

**После обновления расширение нужно перезагрузить руками** — в
`browser://extensions` (или `chrome://extensions`) кнопкой «Обновить» у
расширения. Распакованные расширения браузер сам не перечитывает, а с версии
0.2.0 у него ещё и новые разрешения, поэтому без перезагрузки страницы
управляться не будут.

## Установка

Расширение ставится **распакованным**: оно живёт в этой папке репозитория, и
Jarvis кладёт сюда файл с токеном. Упаковывать в `.crx` не нужно.

### Chrome, Яндекс Браузер, Edge, Opera

1. Запусти Jarvis хотя бы раз — он создаст `extension/token.json`.
2. Открой `chrome://extensions` (в Яндекс Браузере — `browser://extensions`).
3. Включи **режим разработчика** (переключатель справа сверху).
4. Нажми **«Загрузить распакованное расширение»** и укажи папку `extension`
   внутри проекта — у тебя это `D:\Jarvis\extension`.
5. В логе Jarvis появится строка «Расширение подключилось».

### Firefox

1. Открой `about:debugging#/runtime/this-firefox`.
2. **«Загрузить временное дополнение»** → выбери `manifest.json` в этой папке.

Firefox снимает временные дополнения при перезапуске — это ограничение самого
браузера, а не расширения.

## Что оно умеет

| команда | что делает |
|---|---|
| `open` | открыть адрес; с `reuse` — перейти на уже открытую вкладку этого сайта |
| `open` со списком `urls` | служебная страница браузера: адреса перебираются, пока какой-нибудь не откроется — схема у Яндекса `browser://`, у Chrome `chrome://`, у Firefox `about:` |
| `tabs` | перечислить вкладки: заголовок, адрес, окно, группа; плюс `current` — где пользователь сейчас |
| `activate` | показать вкладку и поднять её окно |
| `close` | закрыть вкладку по номеру или все вкладки сайта |
| `target` | сказать, к какой вкладке относится команда, ничего не делая |
| `page` | выполнить в странице план шагов (см. ниже) |
| `probe` | перечислить кнопки страницы: подпись плюс селектор |
| `ping` | проверка связи |

Команды приходят от Jarvis, ответ уходит с тем же `id`. Добавить новую —
это ветка в `run()` в `background.js` и вызов `self._extension.call(...)`
в `skills/browser/skill.py`.

## Работа внутри страницы

Код, который выполняется в странице, лежит в `page.js` и **только там**. Из
Jarvis приходят данные: список шагов-вариантов. Выполняется первый сработавший.

```json
[{"click": ["[data-test-id=\"NEXT_TRACK_BUTTON\"]"]},
 {"label": ["нравится"], "avoid": ["не нравится", "убрать"]},
 {"media": "forward", "seconds": 30}]
```

Слово ищется с начала слова, а границей считается любой не-буквенный символ —
иначе кавычки в «Поставить отметку "Нравится"» приклеиваются к слову. Запрет
сильнее совпадения: без `avoid` лайк оказывается дизлайком, потому что по-русски
отрицание стоит перед словом и «не нравится» содержит «нравится» целиком.

| шаг | что делает |
|---|---|
| `media` | сам плеер: play, pause, toggle, mute, unmute, louder, quieter, forward, back. Работает на любом сайте с `<video>` или `<audio>` |
| `label` | нажать кнопку, в подписи которой есть одно из слов (`aria-label`, `title`, текст) и ни одного из `avoid` |
| `click` | нажать первый видимый элемент по списку CSS-селекторов |

В ответе приходит `sel` — селектор, который сработал. По нему Jarvis потом
понимает, куда нажал: если нажалось не то, эта кнопка попадает в «сюда больше
не надо» и выпадает из следующего плана.

Впрыскивается во все кадры сразу: плеер часто живёт во вложенном фрейме.
Проверить интерпретатор без браузера: `node extension/selftest.js`.

Чего он не умеет и не будет: выполнять код, пришедший снаружи. Селектор уходит
в `querySelector`, подпись — в сравнение строк. Голос проходит путь микрофон →
Whisper → LLM → аргумент, и превращать его в исполняемый код нельзя ни на одном
шаге — по той же причине, по которой название программы не отдаётся в оболочку.

**Полноэкранного режима среди шагов нет намеренно.** Браузер разрешает его
только по живому нажатию человека; синтетический клик такого права не даёт, и
команда молча не сработала бы.

## Безопасность

Порт на `127.0.0.1` доступен любой странице в браузере: код на сайте может
открыть `ws://127.0.0.1:8765` и притвориться расширением. Поэтому проверок две.

**Origin.** Браузер подставляет его сам, и со страницы подделать нельзя.
Jarvis принимает только `chrome-extension://` и `moz-extension://`.

**Токен.** Лежит в `token.json` рядом с этим файлом. В
`web_accessible_resources` он не объявлен, поэтому страницам сайтов недоступен —
прочитать его может только само расширение. Файл в `.gitignore`, в репозиторий
не попадает.

Одной проверки мало: origin не спасёт от постороннего приложения на этой же
машине, токен — от расширения, поставленного мимо нас.

Разрешения: `tabs` (заголовки и адреса вкладок), `alarms` (просыпаться и
переподключаться), `scripting` плюс доступ ко всем сайтам — без него внутри
страницы не нажать ни одной кнопки. Это самое серьёзное из разрешений, и
браузер честно предупредит о нём при установке. Работает оно только по команде:
код впрыскивается в момент выполнения шага и ничего не делает фоном, страницы
не читаются и наружу не уходят. Не нужно управление страницами — убери
`scripting` и `host_permissions` из `manifest.json` и перезагрузи расширение:
вкладки, поиск и служебные страницы продолжат работать, а команды вроде «пауза»
станут честно отказывать.

## Если не подключается

- Нет `token.json` — запусти Jarvis, файл появится сам.
- В логе Jarvis «Отказано в подключении: origin …» — расширение поставлено не
  распакованным либо в браузере, схему которого мы не знаем. Допустимые
  префиксы задаются в `config.yaml`, `browser.extension.origins`.
- В логе «неверный токен» — расширение читает старый `token.json`. Убери
  расширение и загрузи заново.
- Ничего не происходит и логов нет — служебный поток уснул. Открой
  `chrome://extensions`, нажми «Служебный процесс» у расширения: консоль
  оживит его и покажет ошибки.
